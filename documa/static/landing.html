Meet the 3 Autonomous Agents

A modular multi-agent pipeline designed for precision procurement audit.

AGENT 1

Multimodal Vision Agent

Powered by Gemini 3.5 Flash via the google-genai SDK. Ingests scanned receipts, multi-page PDF contracts, and bill of lading manifests to extract structured line items, dates, subtotal, taxes, and vendor signatures.

AGENT 2

Contract Auditor Agent

Cross-references parsed invoice data against master Purchase Orders stored in Firestore. Performs item-by-item price auditing to detect unit-price inflation, quantity discrepancies, and unapproved freight surcharges.

AGENT 3

Discrepancy Dispatcher

Evaluates audit severity. Auto-authorizes instant payout for compliant receipts, drafts formal Markdown vendor dispute reports for price inflation, and surfaces escalation alerts for 1-click human finance approval.

Got Questions?

Frequently Asked Questions

How does Gemini 3.5 Flash extract data from messy physical receipts?

Documa uses Gemini 3.5 Flash's native multimodal vision model to process high-resolution images, multi-page PDFs, handwritten notes, and low-contrast paper receipts. It outputs structured JSON conforming to Pydantic schemas.

What happens when a price overcharge or unapproved fee is detected?

The Discrepancy Dispatcher Agent automatically formats a formal Markdown Vendor Price Discrepancy Notice detailing the exact itemized variance and contract rates. If the discrepancy exceeds threshold rules (e.g. overcharge > $500), it escalates to finance leaders for 1-click approval.

Can Documa run offline or without GCP credentials?

Yes! Documa features resilient fallback modes for Firestore and Cloud Storage. If running locally without GCP credentials, it uses in-memory PO databases and local filesystem storage.
